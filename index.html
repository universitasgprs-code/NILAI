⚠️ Apps Script Perlu Di-Deploy Versi Baru

Penyebab: Aksi tidak dikenali oleh server doPost Google Apps Script.
Google Apps Script di Google Drive Anda masih menjalankan versi lama sebelum fitur ini ditambahkan.
💡 Cara Mengaktifkan Fitur Terbaru (Hanya 1 Menit):
  1. Klik tombol hijau "📋 Salin Kode GAS Terbaru" di bawah.
  2. Buka tab script.google.com tempat proyek Apps Script Anda.
  3. Hapus semua kode lama di editor (Ctrl+A lalu Del), kemudian Tempel (Paste) kode terbaru. Lalu tekan Ctrl + S.
  4. LANGKAH PALING PENTING:
    Klik menu Deploy (Terapkan) ➔ pilih Kelola penerapan (Manage deployments).
    Klik ikon Pensil (Edit) pada penerapan aktif.
    Pada bagian Versi (Version), ubah ke "Versi baru" (New version).
    Klik tombol Terapkan (Deploy). Selesai!
